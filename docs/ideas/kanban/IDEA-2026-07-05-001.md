# Dashboard — détail sous-catégories + ventes/dons/recyclage (retour La Clique)

---

## 2026-07-05 — Retour utilisatrice La Clique (déclarations éco-organismes)

**Contexte :** utilisatrice de la ressourcerie pilote **La Clique Qui Recycle** en train de faire ses déclarations aux éco-organismes. Module décla éco-organismes **pas encore livré** en v2 (story **9.1** backlog) — besoin exprimé pour le **prochain socle V2**.

**Verbatim (reformulé) :**

> J'ai vraiment hâte qu'on puisse avoir sur le dashboard de Recyclique le détail des sous-catégories pour les réceptions et les sorties. Et que les sorties puissent distinguer les ventes/dons de ce qui part au recyclage… Ça changera ma vie !!!

**Besoins identifiés :**

1. **Réceptions (entrées)** — voir le détail par **sous-catégorie**, pas seulement la catégorie racine.
2. **Sorties** — voir le détail par **sous-catégorie**.
3. **Sorties — typologie de flux** — distinguer au minimum :
   - ventes ;
   - dons ;
   - matière partant au **recyclage** (et éventuellement déchèterie / autres destinations déjà saisies en réception).

**Impact utilisateur :** préparation des déclarations éco-organismes ; aujourd'hui la personne compense en dehors de Recyclique faute de granularité dashboard.

**État produit actuel (v2, juillet 2026) :**

- Dashboard `/dashboard` (story **5.2** done) : graphiques réceptions et sorties **agrégés au parent** (`/v1/stats/reception/by-category`, `/v1/stats/sales/by-category`).
- Pas de drill-down sous-catégories sur le dashboard.
- La réception saisit déjà `destination` (RECYCLAGE, DECHETERIE…) et `is_exit` — **non reflété** dans les stats dashboard actuelles.
- Module éco-organismes : vision + pack brownfield 1.4.4, implémentation v2 à faire (Epic **9**).

**Pistes de cadrage V2 :**

- **Epic 5** — enrichir le dashboard stats (nouvelle(s) story(s) post-5.2) : endpoints + widgets sous-catégories ; découpage sorties ventes / dons / recyclage.
- **Epic 9** — module décla éco-organismes (9.1) : s'appuyer sur les mêmes agrégats matière pour pré-remplir les déclarations.
- Données déjà disponibles côté modèle réception / caisse — surtout travail **reporting + UX dashboard**.
